# Dispatch mark

One shared prompt becomes three answer lanes inside a speech frame. The mark is
a single filled path with three cutouts, so the same geometry works at bar size
and as a larger project icon.

- Light: warm ivory `#e6e5dd` on dark backgrounds.
- Dark: charcoal `#171a20` on light backgrounds.
- QML: `DisparchyIcon.qml` uses the same 64 × 64 path and follows the active theme.
